# ລະບົບບັນຊີເກັບເງິນກອງທຶນ (Streamlit + SQLite)

## ຕິດຕັ້ງ / ເປີດໃຊ້
    python -m pip install -r requirements.txt
    python -m streamlit run app.py

## ອັບເກຣດຈາກເວີຊັນເກົ່າ (ຂໍ້ມູນບໍ່ຫາຍ)
ຄັດລອກສະເພາະ app.py, db.py, requirements.txt ແລະ ໂຟນເດີ .streamlit ໄປທັບຂອງເກົ່າ.
ຢ່າລຶບ fund.db — ຕາຕະລາງຜູ້ໃຊ້ຈະຖືກເພີ່ມເຂົ້າໄຟລ໌ເກົ່າອັດຕະໂນມັດ.

## ສິດການໃຊ້ງານ
- ຄົນທຳອິດທີ່ລົງທະບຽນ = Admin. ຄົນຕໍ່ໄປລົງທະບຽນແລ້ວຕ້ອງລໍ Admin ອະນຸມັດ (ໜ້າ "ຈັດການຜູ້ໃຊ້").
- ຜູ້ໃຊ້ທົ່ວໄປ: ເບິ່ງ/ຄົ້ນຫາ, ປ້ອນລາຍການໃໝ່ (ບວກເພີ່ມເທົ່ານັ້ນ) ໃນເດືອນຫຼ້າສຸດ. ແກ້/ລຶບບໍ່ໄດ້.
- Admin: ແກ້ໄຂບັນຊີ, ເປີດເດືອນໃໝ່, ລັອກເດືອນ, ປັນຜົນ, ນຳເຂົ້າ Excel, ສຳຮອງ, ເບິ່ງບັນທຶກການເຄື່ອນໄຫວ.
- ລະຫັດຜ່ານເກັບແບບ hash (PBKDF2), ໃສ່ຜິດ 5 ຄັ້ງລັອກ 5 ນາທີ, ທຸກການປ້ອນ/ແກ້ໄຂມີບັນທຶກ.

## ຄວາມປອດໄພ
ການປ້ອງກັນນີ້ຄຸ້ມຄອງ "ໜ້າແອັບ". ໄຟລ໌ fund.db ຍັງເປັນໄຟລ໌ປົກກະຕິໃນຄອມ, ໃຜເຂົ້າເຖິງເຄື່ອງ/ໂຟນເດີ
ໄດ້ກໍ່ເປີດໄດ້. ສະນັ້ນໃຫ້ແລ່ນແອັບໃນຄອມຂອງ Admin ແລ້ວໃຫ້ຜູ້ໃຊ້ເຂົ້າທາງ browser ເທົ່ານັ້ນ
(streamlit run app.py --server.address 0.0.0.0, ເຂົ້າທີ່ http://IP-ຄອມ:8501), ແລະ ສຳຮອງ fund.db ເປັນປະຈຳ.
